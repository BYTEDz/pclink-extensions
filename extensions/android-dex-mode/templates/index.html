Setup & Wireless ADB Guide
1
Developer Options Open Settings > About Phone > Version and tap Build Number 7 times until developer mode is unlocked.
2
Enable Wireless Debugging Navigate to Developer Options and toggle Wireless Debugging ON while connected to Wi-Fi.
Open Screen on Phone
3
Pairing (Android 11+) Tap Pair device with pairing code. Note the 6-digit code and dynamic pairing port (e.g. 37821), then click Pair (v11+) below.
4
Connect & Launch Enter the primary IP address and port shown under Wireless Debugging (e.g. 43049 or 5555), click Connect ADB, and start the Android DeX session.
